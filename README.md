# DAY PEOPLE · Notion → Telegram

Бот **@daypeople_notion_bot** каждую минуту проверяет Notion (DAY PEOPLE · HQ) и пишет в общую группу:
кто что создал, изменил, удалил или прокомментировал — одним сообщением, со ссылками.

## Команды в группе
| Команда | Что делает |
|---|---|
| `/task текст` | новая задача в «Задачи» |
| `/idea текст` | идея (статус «Идеи») |
| `/claude текст` | задача для Claude |
| `/gpt текст` | задача для GPT |
| `/vitya текст`, `/dima текст` | задача для Вити / Димы |
| `/help` | список команд |

Первая строка — название, всё остальное — описание задачи. Бот отвечает ссылкой на созданную страницу.

## Как устроено
- `notion_watch.py` — вся логика; работает в GitHub Actions: один запуск живёт ~55 минут, проверяет всё раз в минуту и сам запускает следующий; расписание раз в 30 минут — запасной перезапуск (`.github/workflows/notion-watch.yml`).
- Секреты репозитория: `NOTION_TOKEN` (подключение «DAY PEOPLE Telegram bot» в Notion), `TELEGRAM_BOT_TOKEN` (от @BotFather).
- Состояние между запусками хранится в кэше Actions в зашифрованном виде — названия страниц наружу не попадают.
- `image.png` — логотип: из него бот ставит аватарку себе и обложку группе (обновляется при замене файла).
- Ручной запуск: Actions → notion-watch → Run workflow.
