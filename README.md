# DAY PEOPLE · Telegram-бот

**@daypeople_notion_bot** живёт в общем чате DAY PEOPLE (Витя, Дима).

| В чате | Что происходит |
|---|---|
| `Claude, сделай …` | задача для Claude в Notion (статус «Делаем») |
| `#реф` в сообщении | референс уходит на страницу «Референсы» в Notion |
| 👍 **Ок** под готовой работой | задача в Notion → «Готово» |
| ✏️ **Правки** под готовой работой | бот спрашивает «что поправить?», ответ уходит в задачу, задача → Claude |
| `/help` | подсказка |

Готовые работы (видео, картинки) присылает Claude с Mac Вити скриптом `send_to_tg.py` — с кнопками `ok:<id>` / `fix:<id>`.

## Устройство
- `bot.py` — вся логика; GitHub Actions держит один запуск ~55 минут (long polling) и сам запускает следующий; расписание раз в 30 минут — запасной перезапуск.
- Секреты: `NOTION_TOKEN` (подключение «DAY PEOPLE Telegram bot»), `TELEGRAM_BOT_TOKEN`.
- Состояние хранится в кэше Actions в зашифрованном виде.
- `image.png` — логотип: аватар бота и фото группы.
